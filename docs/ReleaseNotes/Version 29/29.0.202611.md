# Dysel BC 29.0.202611

| Case No. | Module | Comment |
| --- | --- | --- |
| 69436 | General | Implemented UI for work order, maintenance, rental, and consolidated documents to allow the user to see failed postings when posting by job queue. These fields and factboxes are only visible when the posting by job queue is set up in the `Sales & Receivables Setup`. |
| 69323 | Equipment | Sales Configurator now retains the selected vendor when the same equipment model is revalidated, including nested configurations. Blank vendor values and changes to a different model continue to use the model's default vendor. |
| 69472 | Equipment | Corrected equipment posting statuses when shipping and invoicing a sales order with multiple equipment objects. Only objects with an invoiced quantity become Sold; shipped objects without an invoiced quantity remain Delivered. |
| 69510 | Parts | Corrected an issue where line discounts were not carried over on Sales Orders and Sales Quotes when a customer had a different bill-to customer and was using Sell-to Customer as the price and discount source. Eligible discounts for items and item discount groups now match the Sell-to customer when a different default Bill-to is populated. |
| 69484 | Service | Fixed Work Order Post Usage failing when multiple items have insufficient stock. Errors now receive unique IDs, preserving each item's stock error while eligible lines continue to post. |
| 69493 | Service | Work Order Quote and Order Group(Resource) lines now calculate Line Cost (LCY) from quantity and unit cost using General Ledger Setup rounding. Other line types and Group(Resource) with Link Objects are unchanged. Existing unposted lines update when edited; posted values are not bulk-updated. |
| 69517 | Service | Work Order item lines with lot or serial tracking now support quantities greater than one. Reservation checks remain in place, and usage still requires complete tracking for the quantity being posted. |
| 69547 | Service | Maintenance Contract Order Manager now uses the Sell-to Customer's Salesperson when an Order is created, including conversion from a Maintenance Quote, or either customer is changed through a permitted flow. Customer changes replace any existing Order Manager, including a manual value; a blank Sell-to Salesperson clears the field instead of falling back to Bill-to. Existing contracts are not bulk corrected and retain their stored manager until a permitted customer change. Maintenance Quote defaulting is unchanged. |
| 69442 | Rental | Periodic invoicing of rental contracts with Overtime Billing = In the Contract now calculates overtime and adds the overtime line to the invoice. Fixed Unit Price lines are invoiced without overtime. |
| 69461 | Purchase | Fixed equipment Book Value doubling when undoing a purchase receipt linked to a Work Order with document line number zero. Existing Equipment and Parts receipt behavior remains unchanged.  |
| 69467 | Purchase | Fixed unreversed GRNI when invoicing an equipment purchase receipt through Get Receipt Lines on a Work Order-linked purchase order. Equipment Purchase and Book Value now reflect the original purchase amount, and GRNI is cleared. |
| 66806 | Integration | In cooperation with TVH North America, we have implemented several integrations to allow direct communication between Dysel BC and TVH. This will greatly simplify price and availability retrieval, order submission, and will obsolete the catalogue imports for TVH. Please read the release notes on the specific integrations for more information.<br><br>**Note**: This functionality is currently only available in North America. |
| 68544 | Integration | Created price and availability check for TVH parts on the purchase order. This will enable users to retrieve the real-time pricing and part availability, as well as secondary information, directly from the TVH database. |
| 68545 | Integration | Created the possibility on the purchase order to submit parts orders directly to TVH. This will prevent a lot of overhead and leave less room for manual error by directly moving the purchase order to TVH's sales system.<br><br>**Note**: This functionality is currently only available in North America. |
| 68546 | Integration | Added the option of importing and displaying parts images directly from the TVH database. By design, this is a two-step process. TVH will distribute a pre-formatted file to the end customer that can be downloaded and imported into Dysel BC. The images will then be retrieved appear automatically. Since the import contains url endpoints rather than image files, the tax on the database is minimal.<br><br>**Note**: This functionality is currently only available in North America. |
| 68547 | Integration | Added punchout/punchback functionality on the sales order, work order, and purchase order. If a part is not in the BC item master, this functionality will allow the user to directly access the TVH catalogue from Dysel BC, select the part(s), and punch them back to Dysel BC, where the item will automatically be created (if it does not exist) and added to the document lines.<br><br>**Note**: This functionality is currently only available in North America. |
| 69508 | Projects | Project approvals are now limited to users designated as Project Approvers in User Setup and assigned to the project. Existing approver assignments are carried over to the new fields during upgrade, but each approver must be designated separately. After upgrading, review project assignments and confirm the intended approvers are enabled in User Setup. |
| 69554 | Mobile Field Service | Fixed timesheet only showing full hours in FRC language |
| 69515 | Transport | Added fields for Measurement Templates in the delivery and return measurement line APIs. This will make it easier to link the datasets together in external applications. |
| 69553 | Transport | Fixed data access issue in delivery and return APIs. The APIs now only return the measurements for their respective measurement types. |

## Notes
