# Dysel BC 28.5.202610

| Case No. | Module | Comment |
| --- | --- | --- |
| 69028 | General | The **Sales Invoice List** now includes Dysel BC-specific **Post**, **Post and Send**, **Preview**, and **Post Batch** actions. |
| 68715 | Equipment | Fixed posting and reversal of work-in-progress transfers for equipment objects. Invoice and cost-of-goods-sold postings now retain the correct equipment object. |
| 68966 | Equipment | Fixed a bug where changing the bill-to customer on a **sales order** with an equipment object could reset the object's status to the default for the object's posting status. |
| 69018 | Service | Fixed an issue that prevented users from attaching files to maintenance contracts. |
| 69330 | Service | Added **Extended Text** to **Work Order Reporting Codes**, allowing default text on a reporting code to transfer to a work order reporting line when the code is assigned. |
| 69390 | Service | The system now prevents users from crediting a posted sales invoice for a work order if related purchase lines have been received but not invoiced. Post the purchase invoices before issuing the credit. |
| 69413 | Service | Postponed the work order shipment usage posting integration feature to support a smoother upgrade from the existing method. Check the [**Features**](/Features/) page for more information. |
| 68972 | Rental | Changing the sell-to or bill-to customer on a rental contract now correctly synchronizes tax area and business posting groups across the header and lines. Open invoice details are updated for future billing, while posted transactions and historical amounts remain unchanged. |
| 69320 | Purchase | Fixed initialization of recurring purchase invoice lines. |
| 67196 | Localization | Fixed an issue in the North American sales tax enhancement that caused tax to be calculated across too many lines. |
| 69426 | Mobile Field Service | Fixed an Action Code error that occurred during a full XML import. |
| 69430 | Transport | Added the Measurement Lookup API, allowing connected systems to select measurements. |
| 69439 | Transport | Added the Transport Vehicle API to support transport planning and vehicle availability checks. |
| 69444 | Transport | Added the Document Status API, which provides external systems with a list of possible statuses for transport documents. |
| 69458 | Transport | The Customer API now exposes `recordId` alongside `systemId`. The Equipment Object and Resource APIs now expose both identifiers. `SystemId` is the OData key for all three APIs. Integrations that use `No.` in resource URLs must migrate to `SystemId`. |
| 68884 | Support Portal | Users can now view previously approved case budgets in the Dysel Support Portal, giving them better visibility into budgets and helping them manage spending. |
| 69418 | Support Portal | After signing in to the Dysel support site, users can select **Security Advisories** to review advisories about recently patched vulnerabilities in Dysel apps. |
